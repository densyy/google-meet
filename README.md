# MeetGo

## Descrição

MeetGo é um webapp que facilita entrar em reuniões do Google Meet usando código. O app do iPhone escondeu o campo de ID — só entra por link. O MeetGo resolve isso de forma simples, direto do navegador.

## Pré-requisitos

- Navegador web (Chrome, Safari, Firefox)

## Instalação

```bash
# Clone o repositório
git clone https://github.com/densyy/google-meet.git

# Entre na pasta
cd google-meet
```

## Uso

```bash
# Abra o index.html no navegador
open index.html
# ou no Windows:
start index.html
```

1. Digite ou cole o código da reunião (ex.: `abc-defg-hij`)
2. Clique em **Entrar**
3. Será redirecionado para a sala do Meet

## Funcionalidades

- Formatação automática do código da sala
- Salva salas recentes (localStorage)
- Renomear e remover salas salvas
- Botão de colar da área de transferência
